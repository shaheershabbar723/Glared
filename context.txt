# GLARED - AI Fashion Photography Platform - Complete Context

## Overview
GLARED is a modern web application for AI-generated fashion photography services. The platform allows fashion brands and retailers to generate professional-quality product images using AI technology, eliminating the need for traditional photoshoots. The website features portfolio management, user authentication, pricing packages, and contact functionality.

## Technology Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Supabase (Database, Auth, Storage)
- **Payments**: Stripe integration
- **Build Tool**: Vite
- **Icons**: Lucide React

## Project Structure
```
src/
├── components/          # Reusable UI components
│   ├── admin/          # Admin dashboard components
│   ├── Layout/         # Navigation, Footer
│   ├── Portfolio/      # Portfolio display components
│   └── ui/             # Basic UI components (Button, Input, etc.)
├── contexts/           # React contexts (AuthContext)
├── lib/               # Utilities and configurations (Supabase, Stripe)
├── pages/             # Page components
│   ├── auth/          # Authentication pages (SignIn, SignUp, Profile)
│   ├── admin/         # Admin pages (Dashboard)
│   └── ...            # Main pages (Home, Portfolio, About, Pricing, Contact)
└── styles/            # Global styles

supabase/
├── migrations/        # Database schema migrations
└── functions/         # Supabase Edge functions
```

## Database Schema

### Main Tables
- `categories` - Portfolio categories (men/women sections)
- `clothing_items` - Individual clothing pieces
- `clothing_images` - Multiple images per clothing item
- `profiles` - User profile information
- `stripe_customers` - Stripe customer mappings
- `stripe_subscriptions` - Subscription tracking
- `stripe_orders` - Order history

### Authentication Tables
- `auth.users` - Supabase authentication users
- `profiles` - Extended user information with automatic creation triggers

### Storage
- `portfolio-images` bucket for storing clothing item images
- Public read access for portfolio images
- Authenticated write access for admin uploads

## Authentication System

### Features
- Complete sign up, sign in, and profile management
- Email/password authentication
- Password reset flow
- Protected routes
- Session management
- Profile auto-creation on signup

### Implementation
- Uses Supabase Auth with email/password
- Custom profiles table linked to auth.users
- Row Level Security (RLS) policies
- Automatic profile creation trigger
- Session persistence

## Development Workflow

### Getting Started
1. Clone repository
2. Install dependencies with `npm install`
3. Set up environment variables
4. Run database migrations
5. Start development server with `npm run dev`

### Adding New Features
1. Create components in appropriate directories
2. Add routes in App.tsx
3. Update navigation if needed
4. Add database migrations if required

### Styling Guidelines
- Use Tailwind CSS classes
- Follow existing color scheme
- Maintain responsive design principles
- Use consistent spacing and typography

## Deployment
- Build with `npm run build`
- Deploy to hosting platform (Vercel, Netlify, etc.)
- Configure environment variables
- Set up Stripe webhooks for production
