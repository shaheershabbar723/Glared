GLARED is a modern web application for AI-generated fashion photography services. The platform allows fashion brands and retailers to generate professional-quality product images using AI technology, eliminating the need for traditional photoshoots. The website features portfolio management, admin functionality, pricing packages, and contact functionality.

## Core Features
- Portfolio display with category organization
- Admin dashboard for content management
- Pricing information with WhatsApp integration
- Contact form with Supabase integration
- Responsive design for all device sizes

## Target Audience
- Fashion brands and retailers
- E-commerce businesses
- Product photographers and stylists
- Marketing agencies

## Technology Stack
- React 18 with TypeScript
- Tailwind CSS for styling
- Supabase for backend services
- Vite for build tooling
- Lucide React for icons

## Pages Structure

## Data Models
### Categories
- id (uuid)
- name (string)
- section (men/women)
- banner_image (string)
- created_at (timestamp)

### Clothing Items
- id (uuid)
- category_id (foreign key)
- name (string)
- description (text)
- thumbnail_image (string)
- created_at (timestamp)

### Clothing Images
- id (uuid)
- clothing_item_id (foreign key)
- image_url (string)
- display_order (integer)
- created_at (timestamp)

- `VITE_SUPABASE_URL` - Supabase project URL
- `VITE_SUPABASE_ANON_KEY` - Supabase anonymous key

## Development Workflow

### Getting Started
1. Clone repository
2. Install dependencies with `npm install`
3. Set up environment variables
4. Run database migrations
5. Start development server with `npm run dev`

### Adding New Features
1. Create components in appropriate directories
2. Add routes in App.tsx
3. Update navigation if needed
4. Add database migrations if required

### Styling Guidelines
- Use Tailwind CSS classes
- Follow existing color scheme
- Maintain responsive design principles
- Use consistent spacing and typography

## Deployment
- Build with `npm run build`
- Deploy to hosting platform (Vercel, Netlify, etc.)
- Configure environment variables
