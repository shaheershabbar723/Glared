# GLARED - AI Fashion Photography Platform - Complete Context

## Overview
GLARED is a modern web application for AI-generated fashion photography services. The platform allows fashion brands and retailers to generate professional-quality product images using AI technology, eliminating the need for traditional photoshoots. The website features portfolio management, admin dashboard, pricing packages, and contact functionality.

## Technology Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Supabase (Database, Storage)
- **Payments**: Stripe integration
- **Build Tool**: Vite
- **Icons**: Lucide React

## Project Structure
```
src/
├── components/          # Reusable UI components
│   ├── admin/          # Admin dashboard components
│   ├── Layout/         # Navigation, Footer

├── lib/               # Utilities and configurations (Supabase, Stripe)
├── pages/             # Page components
│   └── admin/         # Admin pages (Dashboard)
└── styles/            # Global styles

supabase/
├── migrations/        # Database schema migrations
└── functions/         # Supabase Edge functions
```

## Database Schema

### Main Tables
- `categories` - Portfolio categories (men/women sections)
- `clothing_items` - Individual clothing pieces
- `clothing_images` - Multiple images per clothing item
- `stripe_customers` - Stripe customer mappings
- `stripe_subscriptions` - Subscription tracking
- `stripe_orders` - Order history

### Storage
- `portfolio-images` bucket for storing clothing item images
- Public read access for portfolio images
- Direct write access for admin uploads

## Admin Access

The admin dashboard is accessible directly at `/admin` without any authentication requirements. This simplifies content management for single-user scenarios.

To access the admin panel:
1. Navigate to http://localhost:5173/admin (in development)
2. Navigate to /admin on your deployed site (in production)

## Development Workflow

### Getting Started
1. Clone repository
2. Install dependencies with `npm install`
3. Set up environment variables
4. Run database migrations
5. Start development server with `npm run dev`

### Adding New Features
1. Create components in appropriate directories
2. Add routes in App.tsx
3. Update navigation if needed
4. Add database migrations if required

### Styling Guidelines
- Use Tailwind CSS classes
- Follow existing color scheme
- Maintain responsive design principles
- Use consistent spacing and typography

## Deployment
- Build with `npm run build`
